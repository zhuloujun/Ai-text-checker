# 奏议
臣闻治国之道，莫先于安民；安民之要，莫急于择吏。今天下州县之吏，贤者固多，而贪墨庸懦者亦复不少。彼其在位，上则欺罔朝廷，下则剥削百姓，民之困苦，多由于此。伏望陛下敕吏部，精选守令，严加考课，贤者擢之，不肖者黜之。如此则吏治清而民生安，天下可以大治矣。臣愚昧，不胜惶恐之至。
===
# 奏议
臣窃见近岁边备废弛，将帅多非其人，士卒不习战阵，一旦有警，何以御之？昔太祖、太宗之世，将帅皆身经百战，士卒训练有素，故能所向克捷。今承平日久，武备渐弛，此诚可忧之大者。伏乞陛下简拔将才，严明军令，岁时校阅，以振士气。庶几边陲晏然，社稷永固。
===
# 奏议
臣闻水利者，农之本也。江南之田，全赖陂塘沟渠以资灌溉。近者豪右之家，占塞陂塘以为私田，一遇旱暵，则下流之田尽成赤地。臣请敕所在有司，清查陂塘，凡被侵占者，悉令复旧；其有损坏者，官为修治。如此则水旱有备，而民食可足矣。
===
# 奏议
臣伏见今岁江淮大饥，民多流亡，道路饿殍相望。臣愚以为，宜速发内帑，遣使赈济，且蠲免今年租赋，以苏民困。又闻富室多闭籴以邀厚利，宜令有司劝谕，使出粟平粜，敢有抗违者，从重治罪。救荒如救火，稍缓则无及矣，惟陛下速图之。
===
# 论
论曰：自古国家之败，未有不由于奢侈者也。盖奢则费广，费广则赋重，赋重则民困，民困则乱作。故明君必以节俭为先，躬行于上，而天下化之于下。汉文帝衣弋绨，惜露台百金之费，而海内富庶；隋炀帝穷奢极欲，巡游无度，而宗社遂墟。兴亡之迹，昭然可鉴，为人君者，可不慎哉！
===
# 论
或问：“宋之亡，亡于兵弱乎？”曰：非也。宋之兵虽弱，而其所以亡者，在于内政之不修。自南渡以后，权奸相继，贿赂公行，赏罚不明，士气沮丧。虽有忠义之士，往往不得其用，而用者多非其人。以是而当强敌，其不亡也难矣。故论宋之亡者，当责其人，不当专责其兵也。
===
# 论
论曰：科举之法，所以取士也。然以文取士，未必得真才；而舍文之外，又无以为衡。此古今之所同病也。唐以诗赋取士，宋以经义取士，明以八股取士，其法屡变，而其弊终不能免。要之，取士之法虽善，而得人之道，尤在于上之人能知人善任耳。
===
# 史论
赞曰：元之有天下，以武功兴，而不能以文治守。世祖虽知用儒，而终元之世，汉人、南人不得与蒙古、色目并列，科举时行时辍，士人进身之路狭隘。加以钞法屡坏，财用匮乏，末年灾异频仍，盗贼蜂起，遂至于亡。然其开拓疆宇，混一南北，亦前代所未有也。
===
# 史论
论曰：明太祖起于布衣，驱逐胡元，恢复中华，其功伟矣。然其用法过严，诛戮功臣，株连无辜，动以万计，人主之刻薄，未有甚于此者。至于废宰相、设厂卫，遂开有明一代宦官专权之渐。故论明祖者，当兼其功过而论之，不可偏执一端也。
===
# 墓志
公讳某，字某，世为某郡人。曾祖某，祖某，皆隐德不仕。父某，以儒学教授乡里。公生而颖异，读书一过成诵。弱冠补邑庠生，以文名闻于郡中。屡试棘闱不售，遂绝意进取，筑室于城南，教授生徒，前后数百人，多所成就。公性孝友，事亲以礼，与人交，久而弥敬。以某年某月某日卒于家，享年七十有三。铭曰：学以润身，德以化俗；寿考而终，其名不没。
===
# 墓志
孺人某氏，某郡某公之女也。年十九归于某君，事舅姑以孝闻，相夫子以礼，教子女以义。家素贫，孺人勤于纺绩，以佐其夫读书，夫卒以文学显。晚年诸子皆有成，孺人犹布衣蔬食，不改其俭。以某年卒，年六十有八。子某等将以某月某日葬于某原，乞余铭其墓。铭曰：柔而能刚，俭而能施；妇德之贤，百世可师。
===
# 祭文
维某年某月某日，友人某谨以清酌庶羞之奠，致祭于亡友某君之灵曰：呜呼！君以卓荦之才，抱经世之志，而困于场屋，终老布衣，天之于君，何其啬也！忆昔同窗之日，风雨联床，论文讲道，意气相期，谓当同登云路，共济时艰。孰知一别之后，遽成永诀。今者临穴致辞，泪随声下，君其有知，尚飨！
===
# 祭文
呜呼吾母！儿生三岁而父见背，母以一身抚育诸孤，昼夜纺绩，以供衣食，以资读书。儿稍长，母督课甚严，一字之误，必令改正。今儿幸得一第，方欲迎养以报劬劳，而母遽弃儿而去，儿之罪通于天矣。呜呼痛哉！儿虽欲报恩，其可得乎？伏惟尚飨。
===
# 公文
某府为晓谕事：照得本府所属各县，近因雨水过多，田禾被淹，民生艰难。本府已具文申详上司，请蠲本年钱粮。尔等百姓，务须安心守业，毋得轻信流言，擅离乡土。其有冒充官差、借端需索者，许被害之人指名赴府控告，定行严究，决不姑宽。特此晓谕，各宜凛遵毋违。
===
# 公文
某县为严禁事：照得本县城乡，近有无赖之徒，聚众赌博，因而斗殴抢夺，扰害良民，殊属可恶。除饬差严拿外，合行出示严禁。为此示仰阖邑军民人等知悉：自示之后，务各安分守己，勿蹈前辙。倘敢故违，一经拿获，定即从重惩处。其地保人等知情不报者，一并究治。切切特示。
===
# 论
论曰：史者，所以记事之实，而明是非之公也。然史之难，不在于记事，而在于断事；不在于褒贬之辞，而在于褒贬之当。古之良史，如司马迁、班固，其书传世不朽，盖以其能不虚美、不隐恶也。后世史官，或迫于时势，或溺于私情，曲笔阿附，是非颠倒，而史之为用亦微矣。
===
# 奏议
臣闻盐法之坏，其弊在于官商相结，私盐盛行。今两淮盐课，岁额日亏，而私贩之徒，公然往来于江湖之间，莫之敢问。推原其故，盖由巡盐之官，受其贿赂，纵令私贩，以致官盐壅滞，课额不敷。伏乞敕下该部，严立条例，凡巡盐官吏有纵私者，一体从重治罪，庶几盐法可清，国用可裕。
===
# 论
论曰：天下之事，成于勤而败于惰，成于俭而败于奢，成于谦而败于骄，此古今不易之理也。人之一身，亦犹是也。少而勤学，壮而勤事，老而勤于修德，则虽处穷约，亦足以自乐；苟或反是，虽富且贵，亦必至于败亡。君子观于此，可以知所以自处矣。
===
# 墓志
君讳某，字某，姓某氏。其先自中原徙居闽中，遂为某县人。君幼孤，事母至孝，家贫，业贾以养母，而不废读书。中年以后，家道稍裕，乃广施于乡里，修桥梁，建义塾，恤孤寡，乡人德之。卒之日，送葬者千余人。铭曰：贾而有儒行，富而好施与；乡人之思，与山川俱。
===
# 史论
赞曰：宋之立国，以文治为本，崇儒重道，优礼士大夫，故其时人才辈出，文学之盛，远迈前代。然矫枉过正，重文轻武，兵力积弱，屡为外敌所困，终至于播迁南土，再亡于元。治国之道，文武并用，偏废则危，宋之事亦可以为鉴矣。
