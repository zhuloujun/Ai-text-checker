# 史传
周文翰，字伯渊，衢州西安人。少孤，母教之读书，昼则樵采，夜则诵习不辍。绍兴中举进士，调信州司户参军。时郡守贪暴，民多冤狱，文翰每据法争之，守不能夺。秩满，改知龙泉县。县多山田，岁苦旱，文翰相地势，导溪水为渠，溉田数千顷，民赖其利，号曰“周公渠”。迁通判建康府，会岁饥，文翰发常平仓以赈之，全活者甚众。以疾卒于官，年五十八。士民哭之，为立祠于渠上。

# 史传
赵彦恭，字敬之，宗室子也。性端重，不妄言笑。淳熙中，以荫补官，历知池州、饶州，所至有惠政。尝谓僚属曰：“吏治之本，在于廉平。廉则民信，平则民服，二者备而后可以言治。”在饶州时，有富民以贿请托，彦恭叱出之，且论其罪。朝廷闻其贤，擢为江南东路提点刑狱。巡按州县，平反冤狱数十事。后以直言忤宰相，出知远郡，处之泰然，未尝有怨言。卒年六十二，谥曰清献。
===
# 史传
李允中，字子正，江州德安人。父为县吏，以廉谨称。允中幼颖悟，读书过目成诵。嘉定初登进士第，授江陵府教授。时学校废弛，允中增修学舍，延致名儒，一时士风丕变。擢监察御史，论事切直，不避权贵。尝劾奏某宦官擅权纳贿，章三上，帝始纳之。宦官衔之，诬以他事，出为广南东路转运判官。允中至任，革除苛税，商旅称便。召还，未至而卒，年五十一。
===
# 史传
脱欢帖木儿，蒙古伯岳吾氏。祖从太祖征伐有功，世袭千户。脱欢帖木儿少习弓马，兼通汉文。至元中，以千户从征江南，所至禁士卒剽掠，民多安之。江南平，授同知江西宣慰司事。时新附之地，豪猾并起，脱欢帖木儿抚以恩信，渠魁多降。迁湖广行省参知政事，劝课农桑，兴修水利，湖广大治。以老致仕，卒于家。
===
# 史传
许谦中，字执中，婺州金华人。受学于乡先生，潜心理学，不求仕进。家居教授，四方来学者数百人。其教人，先《小学》而后《四书》，先践履而后文辞，门人多有成就。行省屡辟之，皆辞不就。或问其故，谦中曰：“学未至而仕，犹未能操刀而使割也，徒伤其手耳。”年七十余，犹讲学不倦。卒，门人私谥曰文懿先生。
===
# 史传
王士弘，字克宽，河南洛阳人。至正中，以儒术荐为国子助教。时天下多事，士弘上书言时政十事，大要以节财用、慎刑罚、选守令为先。书奏不报。迁翰林待制，与修三史。士弘博通经史，于辽、金典故尤为精熟，史局诸公多就正焉。及兵乱，士弘避地江南，贫甚，犹手不释卷。明兴，征至京师，以老病辞归，卒于家，年七十有五。
===
# 史传
陈怀德，字仲修，福建莆田人。洪武中以明经举，授户部主事。时方定天下赋役，怀德奉命核实浙西田亩，亲历阡陌，不假吏手，所造图册详密，豪右不得隐匿。太祖嘉之，擢员外郎。永乐初，出为广东布政司参议，岭海之民素苦盗贼，怀德督修城堡，训练乡兵，盗为之衰息。在官清苦，俸入多以周贫士。卒于官，囊中仅余数金，同僚为之敛葬。
===
# 史传
刘文恪，字思敬，江西吉水人。永乐十三年进士，选庶吉士，授翰林院编修。宣德中，预修《太宗实录》，书成，迁侍讲。正统初，上疏言边备废弛，宜选将练兵，以防不虞，言多切中。时王振用事，文恪独不附之，振衔之，出为南京国子监祭酒。文恪在监，严立学规，诸生敬惮。土木之变闻，文恪痛哭，上书请修战守，辞意激切。景泰初召还，未几卒。
===
# 史传
张允明，字德辉，山西蒲州人。成化中以举人授知县，历官至陕西按察副使。允明为政，务在宽简，不事苛察，而奸吏莫敢欺。在陕时，岁大饥，流民数万，允明请发仓粟，且令富户出粟平粜，所活甚众。又以边地多盗，修保甲之法，盗贼稍息。巡抚上其治状，擢按察使。以母老乞归养，许之。家居二十年，以孝闻于乡里。
===
# 史传
杨时泰，字景和，四川成都人。弘治中进士，授刑部主事。审理疑狱，务求其情，多所平反。尚书某尝以私意嘱之，时泰执法不从，尚书怒，然亦无以难之。正德初，刘瑾擅权，时泰上疏论其罪，下诏狱，杖几死，谪戍边卫。瑾诛，复官，累迁南京大理寺卿。时泰性刚直，遇事敢言，然处家孝友，待人宽恕，士论称之。
===
# 史传
钱应奎，字文野，常州武进人。嘉靖二十年进士，授行人。使朝鲜，却其馈遗，国人称之。还朝，迁礼科给事中。时严嵩当国，应奎与同官交章论之，谪为边县典史。在谪所，教民耕织，建社学，士民爱戴。嵩败，召复原官，历太常寺少卿。以疾告归，杜门著书，有《文野集》若干卷行于世。
===
# 史传
何汝霖，字雨苍，广东南海人。万历中举进士，授户部主事，管理通州仓。旧例，仓吏收粮，多以斛面为利，民苦之。汝霖严定斛式，亲自监收，弊为之绝。迁郎中，督饷辽东，时边饷屡缺，汝霖筹划有方，军中赖之。以劳瘁卒于任，年四十九。家无余财，妻子扶柩南归，沿途士民多有设祭者。
===
# 史传
孙承远，字伯寿，浙江山阴人。少负才名，工诗文。天启初举进士，授翰林院检讨。时魏忠贤窃柄，承远独不与交通。忠贤党欲引之，承远谢绝甚峻，遂被中伤，削籍归。崇祯初起复，历官至礼部右侍郎。承远屡言时事，请罢矿税、宽赋役，帝虽嘉纳，然不能尽行。京师陷，承远闻变，整衣冠望阙再拜，自缢于寓所。
===
# 史传
黄道周之门人有曰郑景和者，福建漳浦人。少从道周游，通《易》学，尤精象数。崇祯末，以贡生授县教谕。国变后，隐居山中，躬耕自给，不应征辟。著《易象通》十卷，发明师说，多所创获。晚年目盲，犹令子弟诵经于侧，间为指正。卒年八十一，学者称为石斋先生之后劲。
===
# 史传
王子常，字世恒，陕西三原人。少为诸生，屡试不第，遂弃举业，专意于经世之学。凡天文、地理、兵农、水利之书，无不研究。尝著《关中水利考》，言泾、渭诸渠兴废之由甚详，当事者多采其说。又以乡里多盗，倡立乡约，行之数年，盗贼屏息。卒年六十七，有司上其事，诏旌其门。
===
# 史传
戴君实，字子素，湖广黄州人。宋末举进士，授县尉。元兵南下，君实率乡兵拒守，城陷，被执。元将爱其才，欲用之，君实不屈，曰：“吾食宋禄，岂可事二姓？”元将义之，释之归。君实遂隐于山中，终身布衣。所居有梅数十株，自号梅隐。卒时年八十四，遗命以宋衣冠葬。
===
# 史传
吕世安，字静之，河北真定人。家世业农，世安独好学。至元末以儒学教授荐，历官至翰林修撰。性恬淡，不慕荣利，每公退，闭门读书，客至则谈经史终日。尝与修《经世大典》，考订详审，同僚服其精博。致仕后，归里讲学，从游者甚众。所著有《静之文稿》二十卷。
===
# 史传
沈继先，字述之，苏州昆山人。父以商起家，继先独好学，不事生产。正统中举于乡，授教谕，迁知县。在任三年，讼简刑清，民有“沈青天”之号。某年大水，继先亲率吏民筑堤，昼夜不息，积劳成疾，卒于堤上。县民哀之，立祠堤畔，岁时祭祀不绝。
===
# 史传
余仲安，字君平，徽州歙县人。少随父经商于淮扬，后弃贾业儒，登万历进士。授御史，巡按两淮盐政，深悉商民之弊，奏革浮课数事，商民德之。后巡按浙江，劾罢贪吏十余人，一时风纪肃然。迁大理寺丞，以疾卒。仲安虽起于商家，而廉介过于寒士，人以为难。
===
# 史传
韩彦直，字子温，河南开封人。宋南渡后，家于临安。以父荫补官，历知温州。温州濒海，民多以渔盐为业，官吏苛索，民不聊生。彦直至，减盐课，禁苛扰，民始安业。又尝著《橘录》三卷，记温州柑橘之品类、种植之法甚详，后世言橘者宗之。累官至户部尚书，卒谥庄敏。
