# 志怪
临安有卖饼翁姓葛，居候潮门外。每五更起，和面燃炉，数十年如一日。一夕大雪，有少年叩门求饼，衣单而貌秀，言语清婉。翁怜其寒，延之炉侧，与热饼二枚，不取其值。少年食毕，拜谢而去，行数步，忽不见，雪上亦无足迹。翁心异之。明年春，翁病疫几殆，梦前少年至，以手摩其顶，曰：“一饼之恩，今以相报。”觉而汗出如浴，病遂瘳。邻里闻之，争往买饼，葛氏由是小康。或曰少年乃雪神，或曰狐也，莫能明焉。

吴兴沈氏女，年十六，善刺绣。尝绣鹤一幅，精妙绝伦，悬于中堂。一日，家人晨起，见绣上鹤忽失所在，唯余松石。举家惊骇，四出寻觅。至暮，有鹤自东南来，翔于庭中，久之，复入绣中，羽毛宛然如故，而喙间衔一枝桃花，花色新鲜，非时所有。女父以为不祥，欲焚之。女泣曰：“鹤归而衔花，吉兆也，何焚为？”父乃止。是岁女适同邑王生，夫妇偕老，其绣至今藏王氏。

宣州有古松，大数十围，相传晋时所植。里人祀之，号松公。万历间，有县令恶其淫祀，命伐之。斧斤甫下，树中血出如注，役夫皆奔。令大怒，亲往督之。是夜，令梦一老人，苍颜长髯，衣绿袍，揖而言曰：“某居此千余年，未尝为民害。公若必欲伐之，某亦无所逃。然公之子方在襁褓，愿公念之。”令觉而惕然，遂罢伐，且为立碑。后令之子果登甲科，人以为松公之报云。

# 传奇
元至正末，钱塘有书生柳彦章，家贫好学，寓居西湖孤山之麓。邻有卖花女阿萝，年十七，姿容明秀，每晨过其窗下，必以茉莉一枝置案头，不言而去。如是者半载。彦章心感之，赋诗以谢，中有“一枝冷落书窗雪，胜却人间万斛金”之句。阿萝读之，颊生红晕，自是往来渐密。未几兵起，彦章从军，临行，阿萝剪发一缕赠之，曰：“君若不归，妾终身不字。”后十年，彦章以功授官，归访阿萝，则已削发为尼矣。二人相对泣下，终不能复合。

# 传奇
洪武初，苏州富商顾氏有女曰婉贞，才貌双绝，工诗善琴。父母择婿甚严，久未许人。有寒士陈谨，赁屋其邻，每夜诵书，声琅琅然。婉贞闻而悦之，遣婢以诗试之。谨和诗立就，词意清新，婉贞益敬重焉。事为顾翁所知，大怒，欲逐谨。婉贞跪请曰：“儿非敢自媒，特惜其才耳。父若以贫贱弃人，恐非所以教儿也。”翁默然良久，乃资谨入京应试。谨果擢高第，遂成婚姻。时人传为佳话。

# 传奇
永乐间，有侠士号铁笛生者，不知其姓名，常负一铁笛游江湖间。遇不平事，辄为排解，事毕即去，不受谢。尝过扬州，见豪家子强夺民女，铁笛生直入其门，以笛击案，案裂为二。豪家子惧，叩头请罪，归其女。或问其笛何以不坏，生笑曰：“笛中有心，心坚则笛坚。”后不知所终。或言晚年隐于天台山，吹笛月下，声闻数里，樵者往往闻之。

# 传奇
正德中，有女子冯氏，扬州人，幼失怙恃，依舅氏以居。舅贪利，欲鬻之为妾。冯氏知之，夜遁，易男子服，自称冯生，佣书于南京书肆。主人见其字画端楷，甚器之。居二年，肆中士子无辨其为女者。有太学生方某，与之论文，深相契合，欲以妹妻之。冯氏窘甚，乃以实告。方某大惊，既而叹曰：“奇女子也。”遂自娶之。婚后冯氏助夫治学，方某竟以明经起家。

金陵城南有废园，旧为魏国公别业。园中有池，池畔古柳数株。天启中，有诸生读书其中，夜闻池上笑语，出视之，见数女子浣纱月下，容色艳丽，衣裙皆作前代妆束。诸生趋前揖之，女子相顾而笑，齐入水中，水面唯余纱数匹，随波而逝。明日视池，水浅才及膝，无可藏身之处。诸生惧，即日移去。或言园中旧有宫人殉葬，其魂未散云。

嘉兴有僧名慧明，居精严寺，戒律甚严。一夜坐禅，有虎入寺，蹲于阶下，眈眈视僧。僧神色不动，诵经如故。虎俯首良久，若有所听，及经毕，摇尾而去。明日复至，如是者月余。寺僧皆恐，劝慧明避之。慧明曰：“彼来听经，吾何避焉？”后虎不复至。数年，有猎户言，尝于深山中见一虎，不食生物，惟啖草木，见人辄避，疑即寺中听经者。

杭州有老儒陆某，教授乡里，性迂而诚。每岁元日，必以素纸一张焚于庭中，曰：“告天地，一年之中，未尝欺人。”人或笑之。一年，陆以馆谷之资借贫友，友死无以偿，陆焚其券。是夜梦神人告曰：“汝之素纸，天皆录之。今当益汝寿一纪。”陆后果年八十余乃卒，无疾而终。卒之日，邻人闻空中有乐声。

# 传奇
宣德中，泉州有番商之女，名阿兰，貌若天人，通汉语，好读中国书。有秀才林允中，为其家塾师，与之讲《诗》，阿兰颖悟过人，一听即解。久之，二人情意相通。番商将归国，欲携女同行。阿兰不肯，泣谓允中曰：“妾生于海外，而心在中华。今当别矣，愿君毋忘。”遂以明珠一颗赠之。后允中终身不娶，以珠置案头，每夜读书，珠光照卷，人称为“海珠斋”。

吉安府有江姓者，以伐木为业。一日入深山，见大树中空，内有一物，形如小儿，遍体生绿毛，见人而笑。江惧，欲走，物以手招之，示以一处。江往视之，得人参一本，大如臂，其形宛然人状。归而鬻之，获金百两，遂弃伐木，买田为业。后再入山，觅之不得。里人谓之“山魈献宝”，然亦有谓其不祥者。江氏后三世皆富，人始信其为福。

# 传奇
万历间，杭州有歌妓马湘云，色艺俱佳，名动一时，而性极高洁，非才士不与交。有浙中名士徐文长，尝与之唱和，湘云敬其才，然知其性狷，终不敢以私情相许。后徐生遭变系狱，昔日宾客皆避之，唯湘云变卖首饰，遣人送衣食于狱中，数年不绝。徐生出狱，访湘云于旧居，则已病卒矣。徐生恸哭，为作祭文，辞极悲怆，闻者莫不泣下。

南昌有富室黄氏，筑楼于宅后，楼成而家中屡有怪异：器物自移，夜闻叹息之声。黄氏延道士禳之，道士登楼，良久而下，谓主人曰：“此楼基下有古墓，其主人不安，故作祟耳。”黄氏乃掘之，果得一石棺，中有枯骨及铜镜一面。黄氏择吉地改葬之，且设斋醮。是夜，梦一书生来谢，自言南唐时人，以直言被杀，葬于此地已六百余年矣。自是楼中遂安。
