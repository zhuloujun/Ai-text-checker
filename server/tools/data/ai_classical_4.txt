# 游记
余以九月望日游天台山。晨发县城，行三十里至国清寺，古木参天，钟声远闻，寺僧迎余入，具素斋。饭毕，循溪而上，两山夹峙，流泉激石，声如琴筑。又十余里，至石梁，飞瀑自高崖直下，至梁下复分为二，水沫溅人衣袂，寒气逼人。立观久之，心神俱爽，尘虑顿消。日将暮，宿于方广寺，夜闻松涛如海，竟夕不寐。

# 游记
庚子春，余与二三友人泛舟太湖。舟出胥口，湖面浩渺，烟波无际，远山如黛，隐现于云水之间。午后风起，波涛汹涌，舟人急收帆，泊于西山之下。登岸，访林屋洞，洞深而幽，秉烛入，石乳倒垂，形状万千。出洞，于山家买橘数十，其味甘美，非市中所能及。夕阳西下，湖光如金，乘舟而返，友人皆醉。
===
# 游记
黄山之奇，在松，在石，在云海。余登始信峰，峰势峭拔，松生石罅中，枝干虬曲，若龙蛇之飞舞。俯视深壑，云气弥漫，诸峰出没其间，如岛屿浮于大海之上。须臾，风起云散，群峰毕现，苍翠欲滴。同行者叹曰：“不登黄山，不知天下之奇。”余深然之。下山途中，遇雨，衣履尽湿，然意兴不减。
===
# 游记
峨眉山高出五岳，秀甲天下。余自报国寺登山，经伏虎寺、清音阁，山路盘曲，古木森森。至洗象池，已近黄昏，宿于寺中。夜半，寒气侵骨，拥衾不能寐。黎明，随僧众登金顶观日出，东方渐白，云海翻腾，一轮红日自云中涌出，光芒万丈，照耀群山。僧言天晴之日，有佛光可见，惜余未之遇也。
===
# 游记
雁荡之胜，以灵峰、灵岩、大龙湫为三绝。余至灵峰，时已薄暮，仰视峰峦，形态各异，或如双手合掌，或如老僧入定，寺僧指点，一一为名之。夜宿观音洞，洞依岩而建，凡九层，梯而上，夜深月出，洞中清光照人，几忘身在人间。次日往观大龙湫，瀑布自百丈崖头直泻而下，风吹水散，如烟如雾，洵奇观也。
===
# 序
《梅溪诗集》者，吾友陈君子野之所作也。子野少负隽才，工为诗，而屡困场屋，年四十犹为诸生。然其志不衰，每于读书之暇，吟咏自适。其诗清婉有致，不事雕琢，而情意自深。或咏山水，或写田园，或感时事，皆出于性情之真。今子野裒其所作，得诗三百余首，属余为序。余惟诗者，心之声也，观子野之诗，可以知其为人矣。是为序。
===
# 序
余自少好读史，每览古今兴亡之迹，未尝不掩卷而叹。盖治乱之几，往往见于微末，而当局者迷，旁观者亦未必能察。因不自揆，取《宋史》诸传，择其可为鉴戒者，略加论断，凡若干篇，名之曰《读宋史札记》。非敢自附于作者之林，聊以备遗忘、资考镜而已。读者幸勿以其浅陋而弃之。
===
# 序
乡先辈王公遗集若干卷，其孙某搜辑散佚，历十余年而始成编。公生当明季，目睹世变，其文多感慨时事之作，而语不激切，意在言外。晚岁隐居乡里，课子读书，不问外事，其诗亦转为冲淡。今其孙谋付梓，属余为序。余少时尝亲炙公之謦欬，今读其遗文，如见其人，不能无今昔之感焉。
===
# 跋
右宋人《江山秋色图》一卷，绢本设色，长丈余。其画山势连绵，林木葱郁，秋意满纸，而笔法谨严，设色清丽，非高手不能为。卷后有元明诸家题跋，皆推为神品。余得观此卷于友人斋中，展玩竟日，不忍释手。因识数语于后，以志眼福云。
===
# 跋
此《兰亭》旧拓本，余得之于吴门书肆。纸墨古雅，锋棱犹存，虽不知为何时所拓，然视今之翻刻本，精粗判若霄壤。余每临池，辄取此本对之，觉右军笔意，隐然纸上。书法之道，贵在得其神而不在形似，然非精拓，亦无由得其神也。
===
# 书信
某顿首再拜伯修兄足下：别来三载，思念殊深。前奉手书，知兄近况安善，甚慰。弟自入京以来，碌碌无所成，唯日与书卷相伴，差可自遣耳。京师风俗浮华，士大夫多以交游为事，弟性本疏懒，不能随俗，是以落落寡合。兄在乡里，躬耕读书，其乐何如？每一念及，不胜羡慕。秋深天寒，伏惟珍重。不宣。
===
# 书信
子平贤弟如晤：来书言欲弃举业而专力于古学，其志甚可嘉。然窃有所虑者，家贫亲老，菽水之养，不可一日或缺。古人云“仕而优则学，学而优则仕”，二者本不相妨。愿弟姑勉力于举业，以慰亲心，暇则治古学，亦未为晚也。区区之意，惟弟察之。
===
# 赠序
吾友李君将之官岭南，同人饯之于城东之亭，属余为序以赠。岭南去京师万里，其地多瘴疠，其民多杂居，为吏者往往视为畏途。然李君素以廉能称，所至有声。余知其必能以诚信结民心，以宽简化俗，使远人归服。昔柳子厚谪柳州，而柳人至今祀之，李君勉乎哉！
===
# 记
县东有废寺，旧名兴福，毁于兵火久矣，唯余石塔一座，巍然独存。今岁邑人某某倡议重建，捐资者踊跃，不期年而殿宇落成。余往观焉，见其规模宏敞，丹青焕然，而石塔立于殿后，苔痕斑驳，犹带昔年风雨之色。因思兴废之理，有其时亦有其人，非偶然也。邑人请余记之，遂书其事如右。
===
# 记
吾家旧有书楼三楹，先祖所建，藏书数千卷。兵乱之后，楼毁书散，余每过其遗址，未尝不怆然。今岁稍有余资，乃于故址重建之，规制一如其旧，而藏书仅得旧日之半。然余将日积月累，以复先世之旧观，且以教吾子孙焉。名其楼曰“继述”，志不忘也。
===
# 记
郡城之南有湖，周可十里，旧时莲荷弥望，游人如织。后以淤塞，渐成沮洳。今太守某公至，询于父老，发民浚之，三月而工竣，湖水复清，荷花盛开。太守又于湖心筑亭，名曰“与民同乐”。郡人德之，请余为记。余谓太守之政，不独在此一湖，然即此一湖，亦足以见其用心矣。
===
# 游记
余游杭州之日，适值清明，雨丝风片，西湖烟柳如画。与友人乘舟至孤山，寻林和靖故迹，唯见梅树数株，鹤冢一方。和靖隐居于此，梅妻鹤子，二十年不入城市，其高风千载之下犹令人神往。归舟过断桥，雨止而夕阳出，湖面金光万点，遂痛饮而归。
===
# 序
古之为医者，必通天地之理，达人情之变，然后能察病之源而施其治。今之医者，或徒守一方，或妄逞臆见，杀人多矣。吾友张君，世业岐黄，而独能博览群书，参以己见，积数十年之经验，著为《临证心得》四卷。其言平实，其法可用，读者苟能潜心体会，庶几可以寡过矣。
===
# 书信
仲容足下：前日辱过，匆匆未罄所怀。足下所示近作，辞义俱佳，而篇末数语，稍涉激切，窃以为宜少删润。当今之世，言者易得祸，古人所谓“危行言孙”，正为此也。非敢以此教足下，特以相知之深，不能无言耳。惟足下察之。
===
# 记
余于宅西辟隙地数弓，莳花种竹，名之曰“半亩园”。园虽小，而四时之景具焉：春则桃李争妍，夏则荷香满池，秋则丛菊傲霜，冬则疏梅映雪。每于公余之暇，携一卷书，坐竹下读之，清风徐来，鸟语相和，几忘身在城市之中也。
