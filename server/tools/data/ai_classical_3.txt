# 笔记
今人称县令为“父母官”，其说盖起于汉。《汉书·召信臣传》言其为南阳太守，“视民如子”，民号之曰召父；及杜诗继之，亦有善政，南阳人语曰“前有召父，后有杜母”。后世遂以父母称守令。然考宋人文集，州县官自称“父母”者甚少，多称民之于官耳。至明代，此称始盛行于吏牍之间，甚者乡绅亦以此谀之，失其本意远矣。

# 笔记
宋时馆阁校书，例用黄纸。盖黄檗染纸，可以辟蠹，故名“入潢”。沈括《梦溪笔谈》言，古人写书多用黄纸，有误则以雌黄涂之，其色与纸相近，故改字不露痕迹。今人谓妄改文字为“信口雌黄”，其语盖出于此。然后世纸多用白，雌黄之用渐废，而其语独存，亦可见名物之变迁矣。

# 笔记
余尝过嘉兴，见市中卖蟹者，以稻草缚之，十数为一串，谓之“蟹串”。询其故，言蟹性躁，不缚则相钳伤，缚之则静而不死，可以远售。因忆宋人傅肱作《蟹谱》，言蟹之品类甚详，而不及此法，或当时未有，或偶遗之耳。物之微者，民间自有其术，非载籍所能尽也。
===
# 笔记
京师旧俗，正月十五日夜，妇女相约出游，走桥度厄，谓之“走百病”。其行必过桥，谓可以免疾病。又摸城门钉，以祈生子。此俗明时已盛，沈榜《宛署杂记》载之甚详。余少时居京，犹及见之，灯火之下，钗光鬓影，络绎于道。今则此风渐衰，唯乡间尚有行之者。
===
# 考证
《周礼》言“六艺”，曰礼、乐、射、御、书、数。后世言六艺者，或以为《诗》《书》《礼》《乐》《易》《春秋》，二说混淆久矣。按《史记·孔子世家》言“孔子以诗书礼乐教，弟子盖三千焉，身通六艺者七十有二人”，此六艺当指礼乐射御书数，盖身通之事，非诵读之谓也。若以六经当之，则“身通”二字无所着落。学者辨之可也。
===
# 考证
世传宋太祖“杯酒释兵权”之事，出于《涑水记闻》及《邵氏闻见录》，而《宋史》本纪不载。近人或疑其事为后人附会。余谓此事之细节，容有夸饰，然宋初收诸将兵权，以文臣知州，则确然可考。史家之笔，或详或略，不可以一书之不载而遽疑其无也。要当参诸他书，以求其实耳。
===
# 考证
元代行省之制，前人多以为始于世祖。然考《元史·百官志》，太宗时已有行尚书省之设，特其时规制未备，旋置旋罢耳。至世祖中统、至元间，始定为常制，天下分为十一行省。明初沿之，后改为布政使司，而民间犹称行省，至今不废。此地方制度之大变，治史者不可不知。
===
# 考证
《宋史·食货志》言南宋之经总制钱，其法起于宣和末，至绍兴间而大备，名目繁多，为民之害甚深。然细考其数，经总制钱岁入常在一千数百万缗，于国用所补不少。盖南渡之后，版图日蹙，而养兵之费日增，不得不取于此。论者徒责其苛，而不察其势之所迫，亦未为得其平也。
===
# 笔记
杭州西湖，宋时为游观之胜地。《武林旧事》载，每岁春日，都人士女游湖者，画舫相接，笙歌不绝，至暮方散。然湖水易淤，历代屡加浚治。苏轼知杭州，筑长堤于湖中，人谓之苏堤；明时杨孟瑛又浚之，筑杨公堤。今之西湖，实数百年人力之所成，非尽出于天然也。
===
# 笔记
古人饮茶，多用团饼，碾之为末，以汤点之，谓之点茶。宋时斗茶之风甚盛，以汤花色白、久而不散者为胜。蔡襄《茶录》、徽宗《大观茶论》言之綦详。明太祖以团茶劳民，诏罢之，令进芽茶，自是散茶盛行，泡饮之法遂为天下所宗。今人论茶，但知有泡，不复知有点，亦时代之异也。
===
# 考证
“进士”之名，始见于《礼记·王制》，谓学业有成、可进而为士者。隋炀帝始置进士科，唐因之，遂为取士之要途。唐时进士及第者，每岁不过二三十人，故时人有“三十老明经，五十少进士”之语。宋以后，进士名额渐广，而其贵重亦渐减矣。
===
# 笔记
余友某君，好藏古钱，尝示余以一钱，面文“大观通宝”，背无文，字画瘦劲，云是宋徽宗御书，即世所谓瘦金体也。徽宗书法，自成一家，而其为君则失国辱身，后世惜之。然其书画之精，虽亡国之君，亦不能掩其艺也。钱虽微物，亦足以观一代之风气焉。
===
# 考证
《资治通鉴》记事，起于周威烈王二十三年三家分晋，讫于五代周世宗显德六年，凡一千三百六十二年。司马光与刘攽、刘恕、范祖禹诸人分任其事，历十九年而后成。其取材之富，考订之精，前代史书罕有其比。然其书详于政治而略于文化，此则体例所限，不必苛求。
===
# 笔记
吾乡旧俗，除夕之夜，家家守岁，长幼团坐，围炉谈笑，至晓不寐。小儿辈得压岁钱，以红绳贯之，置枕下，谓可以镇祟。此俗由来已久，宋人诗中多有咏之者。今者城居之人，多以电灯代炉火，然守岁之意犹存，亦可见风俗之不易也。
===
# 考证
明代内阁之权，前后大异。洪武罢中书省，分其权于六部，殿阁大学士仅备顾问，品秩不过五品。永乐以后，阁臣渐预机务；至宣德、正统间，票拟之制成，阁权始重。然阁臣之票拟，须经司礼监批红，故宦官得以乘间窃柄。此明代政治之一大症结，论者不可不察。
===
# 笔记
越中多桥，而绍兴尤甚，城中大小桥梁数百座，舟行其下，往来如织。余尝乘乌篷船游之，船身狭长，篷以竹编而涂以黑油，舟子以足划桨，手持小桨以定方向，其技甚巧。沿河人家，临水而居，门前即是码头，洗衣汲水，皆于河中。水乡风物，宛然如画。
===
# 考证
宋代书院之盛，以白鹿洞、岳麓、睢阳、嵩阳为最著，世称四大书院。朱熹知南康军，重修白鹿洞书院，手订学规，后世书院多遵用之。然北宋书院多为私人所建，南宋以后，官府渐加干预，书院之性质亦随之而变。治教育史者，于此当有所留意焉。
===
# 笔记
余少时见乡间老妪纺纱，手摇纺车，一手引棉，其声呜呜然，终日不息。每一匹布，须纺织月余乃成。今则机器织布，一日可得数百匹，老妪之技遂废。然余每忆其声，辄觉温然有味，盖其中有人情在焉，非机器所能代也。
===
# 考证
元人杂剧，今存者百余种，关汉卿、王实甫、马致远、白朴号称四大家。其文辞之妙，前人论之已详。余独谓元剧之可贵，在其能以俗语入曲，写市井之情态，曲尽人情之变。明清文人之作，辞藻虽工，而生气反逊，盖雅之过而失其真也。
===
# 笔记
苏州园林，以拙政园、留园、网师园、狮子林为最著。其构园之法，在于以小见大，一石一木，皆有深意。明人计成著《园冶》，言造园之要，在“虽由人作，宛自天开”八字。今人游园者，但赏其亭台花木之美，而能会其意者，盖亦鲜矣。
