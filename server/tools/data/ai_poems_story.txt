# 七律·聂小倩
兰若荒寒夜色阴，书生独坐对孤衾。
鬼姝奉命施金诱，正士持心拒夜侵。
燕客剑光驱老魅，宁郎义气护娇琴。
骨归故土魂还日，一段深情抵万金。
===
# 七律·婴宁
笑语嫣然隔竹墙，山花插髻出西庄。
王生拾得梅枝去，痴念牵来鬼母乡。
憨态每惊亲友怪，天真偏惹世人伤。
一朝敛笑为人妇，犹忆当年满径香。
===
# 七律·画皮
青衫书客遇佳人，谁识娇颜是鬼身。
彩笔描来红粉面，狰狞藏尽画皮春。
道人赠拂终无用，乞者含羞剖腹尘。
莫把色心轻误信，世间多少画皮人。
===
# 七绝·崂山道士
慕道崂山意未坚，砍柴百日怨连天。
穿墙一术归夸耀，头撞坚垣笑满前。
===
# 七绝·促织
一虫能系一家愁，宫里争斗岁岁求。
魂化蟋蟀酬父母，功名翻为草虫收。
===
# 七律·香玉
劳山宫里两芳邻，白牡丹妍绛雪真。
黄生爱花痴作客，花神感意化成人。
移根一夕香消尽，泣血三年魄返春。
死后愿为花下草，年年相伴不离身。
===
# 临江仙·小翠
狐女嫁来憨似稚，嬉游不避人讥。王郎痴傻两相依。戏装天子样，巧计解危机。
一朝破瓶招怒骂，翩然含泪辞归。园亭重见旧时衣。为郎谋续娶，自去不言归。
===
# 蝶恋花·莲香
狐鬼争怜同一客。桑子书斋，夜夜灯摇壁。李女情痴魂欲息，莲香赠药回春色。
转世重来犹记昔。二美同归，恩怨都成积。莫笑人间多隔膜，异类情深尤可惜。
===
# 七律·红线
魏博田郎恃重兵，潞州薛帅夜忧惊。
青衣红线辞灯去，金盒星驰取信行。
七百里间还一晓，两军城外罢纷争。
功成拂袖归山水，千古谁知侠女名。
===
# 七律·柳毅传书
泾水寒风牧马嘶，龙君爱女苦相离。
书生仗义传音信，钱塘怒火救娇姬。
辞婚不受千金重，归去重逢百岁期。
洞庭烟波三万顷，至今犹记报恩词。
===
# 七绝·李娃传
长安公子落风尘，雪夜残街乞食身。
一见李娃惊泪下，扶持苦读报深恩。
===
# 七律·霍小玉
长安才子李君虞，一见倾心小玉姝。
誓约山盟犹在耳，婚媒另聘竟成虚。
病中泣血盼郎至，黄衫侠士挟之趋。
临终一恸抛杯去，冤魂不散恨难除。
===
# 浣溪沙·莺莺传
西厢月色照花阴，待月西厢半掩门。张生一见误终身。
始乱终弃悔已晚，重来不见旧时人。空留诗句寄黄昏。
===
# 七律·杜十娘
十娘久困教坊中，一见李郎意自浓。
积宝百箱藏素志，归舟千里托芳踪。
孙富巧言人心变，李甲薄情缘分空。
抱匣投江明月下，万金沉尽恨无穷。
===
# 七律·卖油郎
西湖三月杏花天，卖油秦重慕婵娟。
一年积蓄求一见，彻夜温存守醉眠。
美娘蒙难遭凌辱，秦郎扶救意拳拳。
从良终嫁知心客，真情不在锦衣钱。
===
# 七绝·白娘子
断桥烟雨借伞时，许郎白氏两情痴。
雷峰塔下千年恨，谁教金山水漫之。
===
# 七律·梁祝
十八相送话同窗，草桥结拜意难忘。
英台女扮归家去，山伯方知苦断肠。
马家迎娶花轿急，坟前雷裂两魂翔。
翩翩化作双蝴蝶，千古传情绕碧岗。
===
# 鹧鸪天·孟姜女
新婚三日别夫郎，征夫远去筑城墙。寒衣千里亲缝寄，泪眼长城觅喜良。
城下哭，恨茫茫。长城八百为谁殇。至今海上孤坟在，犹听潮声诉断肠。
===
# 七律·牛郎织女
银河迢递隔天涯，牛郎织女两分家。
老牛临死传神计，天母一簪划海沙。
每到七夕鹊桥会，千年一见泪如麻。
人间多少痴情侣，不及星河一夜花。
===
# 五律·王昭君
汉宫春色老，一去入胡沙。
琵琶声断续，青冢草萋斜。
画工多误美，塞外尽风霞。
和亲安北土，千古念明华。
===
# 七律·木兰
唧唧机声伴夜长，可怜阿爷少儿郎。
策马关山千万里，从军十二载风霜。
将军百战归来日，天子堂前赐锦章。
脱我戎装着旧服，伙伴惊疑是女郎。
===
# 七绝·红拂夜奔
杨府侍姬识异才，夜深红拂叩门来。
灵石店里三侠会，一段风云乱世开。
===
# 七律·虬髯客
太原城里遇真龙，虬髯一见意自穷。
赠尽家财归海外，扶余称帝别英雄。
红拂李靖知天命，棋局输赢在此中。
自古英雄能识主，丈夫何必较雌雄。
===
# 临江仙·倩女离魂
倩女情牵王宙去，病身卧在闺中。离魂千里伴征鸿。五年生二子，归棹恨匆匆。
魂返家中身与合，翁惊疑事朦胧。人间痴绝有谁同。一身分作二，情字最玲珑。
===
# 七律·南柯太守传
槐安国里拜东床，淳于棼得宠荣光。
南柯太守二十载，一朝兵败失公主。
醒来原是槐根梦，蚁穴王城事渺茫。
人生富贵皆如此，醉卧斜阳一梦长。
===
# 七绝·黄粱梦
邯郸道上借仙枕，一梦荣华五十年。
醒后黄粱犹未熟，卢生从此悟尘缘。
===
# 蝶恋花·秋香
华府丫鬟春似绣。三笑因缘，惹得才郎瘦。卖身为奴甘俯首，书童唐寅心肠厚。
一纸诗词情意透。点破机关，喜结鸳鸯偶。莫道风流全浪漫，痴情才子天难负。
===
# 七律·窦娥冤
楚州孤女命多艰，童养媳身嫁未完。
张驴设毒陷婆母，桃杌糊涂断案官。
刑场三愿惊天地，六月飞霜血染栏。
亡父归来重雪冤，至今人说窦娥难。
===
# 七律·赵氏孤儿
屠岸贾谋灭赵门，程婴舍子保孤魂。
公孙杵臼甘赴死，隐姓埋名二十春。
孤儿长大知仇恨，一剑冤雪报先恩。
义士忠魂天地鉴，千秋祠庙享清樽。
===
# 七绝·桃花源
武陵渔父误寻源，落英缤纷入洞天。
出后再寻迷旧路，人间何处觅桃源。
===
# 对联·聊斋
一卷聊斋，鬼狐有情胜人世；
千年孤馆，书生无梦负青灯。
===
# 对联·西厢
待月西厢，一段痴情传后世；
拂墙花影，千年佳话感人心。
===
# 对联·桃花扇
一柄桃花扇，写尽南明兴亡恨；
满腔儿女泪，洒遍秦淮烟雨天。
===
# 对联·梁祝
草桥结拜，三载同窗情未了；
坟前化蝶，千年佳话意长存。
===
# 如梦令·聂小倩
兰若夜深灯暗，书客心坚不乱。
鬼女泣前言，愿脱孽缘苦难。
归葬，归葬，魂返人间相伴。
===
# 七律·辛十四娘
冯生醉入鬼狐乡，十四娘怜识短长。
屡劝狂生收傲骨，终成冤狱入牢房。
巧施奇计迎天子，赦得书郎出罪场。
劝夫修德归山去，一片痴情化雪霜。
===
# 七律·阿宝
孙生痴绝名孙痴，阿宝一言断指时。
魂化鹦哥飞入室，情深岂待世人知。
阿宝感念终相许，孙郎苦读步云墀。
人间自有真情在，精诚所至石能移。
===
# 七绝·王六郎
渔翁夜饮水边亭，鬼友相交意气清。
宁舍替身存一命，终为土地佑乡情。
===
# 七律·席方平
父魂冤陷冥间牢，方平入地诉官曹。
城隍贿赂施锯刑，阎罗昏聩受金毫。
二郎神圣明冤狱，惩恶扬善判分毫。
人间地府同一理，孝心坚似万仞高。
===
# 鹧鸪天·连城
一纸诗笺结素心，乔生割肉救连城。媒言富户终违约，相思成疾两魂惊。
阴司见，泪纵横。重生再续旧时盟。人间自有真情在，死亦相从不负卿。
